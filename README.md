# java-rmi-addition-project
Java RMI project demonstrating remote method invocation with a client, server, remote interface, and RMI registry.
A Java RMI (Remote Method Invocation) project that demonstrates client-server communication by performing addition remotely. The client sends two numbers to the server, the server calculates their sum, and the result is returned to the client. This project demonstrates Java RMI, remote method calls, and distributed application concepts.
